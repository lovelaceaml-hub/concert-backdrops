## Repeatable workflow

1. Acquire the local source file or excerpt. Preserve its bytes and source identity in a private ignored work location.
2. Run [the reference intake tool](../../tools/performance_reference/README.md) for an explicit range. It records input hashes, decoded presentation timestamps and sampled stills. It does not infer choreography or grant review approval.
3. Inspect actual-speed footage and source samples. Annotate performers, shots, weight-bearing limbs, contacts, props, visible/hidden joints, attention and musical landmarks. Do not turn an uncertain limb estimate into a measured fact.
4. Build an editable source performance from permitted motion assets, authored animation and source-informed correction. Use the existing rig's proportions deliberately.
5. Solve the final body, hands, attention and contacts. Bake the whole performance before costume simulation.
6. Simulate and bake the exact garment and prop attachments. Bind each bake to its skeleton, motion, collision settings and software identity.
7. Draw the approved light style from fixed solved poses and cloth geometry. Add trails and environment reactions from those final anchors.
8. Inspect plain-floor and finished versions in motion, verify source/worker identity, then save the exact output and review status.
