# Song scene plates and special figures (phase 1, 2026-11-13)

Painted by the eleven song sessions with gpt-image (media-studio) and checked by them; copied here from the shared Drive folder Assets/ so cloud sessions can use them.
- assets/plates/sNN/: scene plates for song NN (most already 1920x1080 JPEG; a few raw PNG originals are noted in that song's Status/NN.md in the Drive folder).
- assets/song_figures/sNN/: special figure poses for song NN (white line art on black). Prepare them with tools/prepare_figure.py (on the engine-scenes-figures branch) before use, like the shared library in assets/figures/.
Each song's scene plan is in its design doc ("Promo v2: scenes") and its status file Status/NN.md; plain text copies are in the Drive folder Designs/text/.
